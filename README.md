# Instrucciones para el levantamiento

- Clonar el proyecto del repositorio

# BACKEND 

1. Entrar al directorio ./backend
2. Ejecutar el comando:   mvn clean spring-boot:run
3. El proyecto corre en http://localhost:8080

# FRONTEND 

1. Entrar al directorio ./frontend
2. Ejecutar el comando:   npm start
3. El proyecto corre en http://localhost:4200
